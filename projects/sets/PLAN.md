# Sets page redesign plan

1. Preserve the current trainer at `/projects/sets/legacy/`, including its settings, How to Play dialog, scoring modes, results, and styling. Keep the public `/projects/sets/` URL for the new game.
2. Restore the existing green top control bar on the new page. Put **New Game** as its only control on the left, with **Colorblind**, **How to Play**, and **Legacy** aligned on the right. Colorblind should switch the card palette and persist like the old setting.
3. Make the new page start with no cards and no running timer. Clicking New Game shuffles the 81 unique cards and deals 12 into a grid of three rows and four columns.
4. In the new game, allow players to select and deselect cards. After three selections, use the existing four-feature `isSet` rule. A valid set increments Correct, records the three cards and elapsed time in Solved Sets, and replaces the cards from the remaining deck. An invalid triple increments Wrong, briefly marks the cards red, and clears the selection so play can continue.
5. Put **Add 3** beside the board. It is available throughout an active game. If any set exists among the visible cards, clicking it increments Wrong, flashes the button red, and leaves the board and deck unchanged. If no set exists, deal up to three remaining cards. As valid sets are removed from a board larger than 12 cards, remove those cards without replacing them until the board returns to 12; on a 12-card board, replace from the deck. Avoid duplicate cards.
6. Start an elapsed timer on New Game and update Correct, Wrong, Time, and Solved Sets during play. When the deck is empty and the visible board has no set, stop the timer and show a finished state with the final statistics. Keep New Game available to reset and start a fresh shuffle.
7. Update How to Play for the new board while retaining the existing feature examples. Make card selection, feedback, and Add 3 usable with keyboard and assistive technology. Verify set detection, board/deck transitions, Add 3 penalties, completion, and the preserved legacy page with focused tests and a browser check.
